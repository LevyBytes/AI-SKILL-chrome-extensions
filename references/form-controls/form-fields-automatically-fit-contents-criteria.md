* The input element has `field-sizing: content` applied.
* The input element has a minimum inline size (`min-inline-size` or `min-width`) applied.
* The input element has a maximum inline size (`max-inline-size` or `max-width`) applied.
* The textarea element has `field-sizing: content` applied.
* The textarea element has an explicit `height` of `auto` or `fit-content` applied.
* The textarea element has an explicit inline size (`width` or `inline-size`) applied.
* The textarea element has a minimum block size (`min-block-size` or `min-height`) applied.
* The textarea element has a maximum block size (`max-block-size` or `max-height`) applied.
* The select element has `field-sizing: content` applied.
* The select element has a maximum inline size (`max-inline-size` or `max-width`) applied.
